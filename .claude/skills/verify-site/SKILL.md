# Перевірити сайт

## 1. Запустити

```bash
npm run verify          # повна: збірка + файли + браузер (~30 с)
npm run verify:quick    # без браузера (~0,5 с) — коли змінив лише текст чи HTML
```

Обидві команди — обгортки над `node .claude/skills/verify-site/verify.mjs` (прапорці `--quick`, `--no-build`). Код виходу 1, якщо є хоч один ❌.

Що перевіряє, щоб правильно пояснити результат:
- **без браузера:** `npm run build`; свіжість `styles.css`/`script.js`; тільки справжні телефони (Максим, Ілля) і обидва на місці; унікальні `id`; якорі `#…` ведуть на секції; локальні файли існують; у картинок є `alt` і вони до 500 КБ; кожен `#id`/`.class`/`[data-…]` із `src/script.ts` є в HTML; у SCSS немає hex поза `_tokens.scss` (локальні `$змінні` вгорі файлу дозволені);
- **у браузері** (headless Chrome, сам піднімає сервер — `npm run serve` не потрібен): ширина сторінки на 1280px і 390px (при помилці — список винуватих елементів); видимість меню/бургера/кнопки дзвінка; калькулятор, фактури, «до/після», фото портфоліо, лайтбокс, FAQ, форма, мобільне меню, кнопка дзвінка; помилки консолі;
- **ℹ️ не помилки:** список заглушок `[…]` і ДЕМО-цін — просто нагадування, що ще чекає на дані.

## 2. Подивитись скриншоти

Повна перевірка друкує шляхи до `desktop-1280.png` і `mobile-600.png` (600px — це вже мобільна версія; вужче headless Chrome не вміє). **Відкрий обидва** і глянь очима: зламана верстка, наїзд тексту, порожні місця — те, що автоматичні перевірки не ловлять.

## 3. Звіт користувачу

- Коротко: «N ✅, M ❌», далі тільки ❌ і ⚠️ — **що зламано, де, і чому це важливо** простими словами. Не переписуй усі ✅.
- Кілька ❌ часто мають одну причину: якщо скрипт упав (❌ «Консоль без помилок»), далі не працює все після нього — назви першопричину, а не 5 окремих поломок.
- Запропонуй виправлення, але **не виправляй мовчки** — спершу спитай.
- Якщо все ✅ — скажи це одним рядком і додай, що побачив на скриншотах.

## Якщо щось не так із самою перевіркою

- «Chrome/Edge не знайдено» — задай `CHROME_PATH` або запусти `--quick`.
- Тест у `probe.html` упав, а на сайті все працює (наприклад, змінилась розмітка навмисно) — поправ тест у `probe.html`, а не сайт, і скажи про це.
