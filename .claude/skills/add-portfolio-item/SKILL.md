# Додати роботу в портфоліо

Портфоліо — сітка `.works-grid` у секції `#portfolio` файлу `index.html`. Кожна картка — `<button class="work" data-work>`. Скрипт сам рахує картки, тож **ніде не треба міняти кількість робіт**. Блок «до/після» (`.ba`) цим skill-ом не чіпаємо.

## 1. Зібрати дані

Потрібні:
- **шлях до фото** (jpg, jpeg, png, webp, jfif, heic; можна кілька — тоді кроки 2–4 для кожного). Якщо назву дали без шляху чи розширення — пошукай у Downloads, Desktop, Pictures;
- Якщо не виходить подивитись фото (.jfif, .heic) — спершу конвертуй його скриптом у тимчасовий .jpg у scratchpad (`-MaxSide 1000`) і подивись уже його;
- **опис** для `alt` і підпису в лайтбоксі: тип стелі + приміщення, за бажання місто. Приклад: «Матова стеля з підсвіткою, вітальня, Черкаси».

Якщо опису немає — подивись на фото і **запропонуй** опис, але спитай підтвердження. **Не вигадуй** того, чого не видно і не сказали: місто, площу, ціну, терміни, ім'я клієнта. Не знаєш міста — просто не пиши його.

## 2. Стиснути фото

Назва файлу: `РРРР-ММ-<опис-латиницею>.jpg` (дата — сьогоднішня, якщо не сказали іншу), малі літери, слова через дефіс, транслітерація без апострофів: «Матова стеля, кухня» → `2026-11-matova-stelia-kukhnia.jpg`. Якщо такий файл уже є — додай `-2`, `-3`.

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File .claude/skills/add-portfolio-item/optimize-photo.ps1 \
  -Source "<шлях до оригіналу>" -Destination "images/portfolio/<назва>.jpg"
```

Скрипт зменшує довшу сторону до 1600px, стискає в JPEG і повертає фото з телефона правильно. Оригінал не змінюється. Якщо оригінал — уже маленький JPEG і перестиснутий вийшов би більшим, скрипт просто копіює оригінал. Якщо результат усе одно більший за ~400 КБ — додай `-Quality 72`.

Якщо скрипт написав **«УВАГА: фото маленьке»** — обов'язково передай це користувачу: таке фото буде розмитим у лайтбоксі, краще попросити в Максима оригінал (не з месенджера). Додавати чи ні — вирішує користувач.

## 3. Вставити картку

Візьми розмітку з [template.html](template.html), підстав `{{FILE}}` і `{{ALT}}` (у `alt` екрануй `"` як `&quot;`).

- Нова робота йде **першою** в `.works-grid` (найсвіжіші зверху).
- Поки в сітці є **заглушки** (кнопки з `<div class="work__bg">` і підписом «Фото роботи»), **видали одну останню заглушку** — щоб сітка лишалась рівною. Коли заглушок не лишилось — просто додавай.
- Решту `index.html` не чіпай.

## 4. Зібрати й перевірити

1. `npm run build` — без помилок.
2. Файл `images/portfolio/<назва>.jpg` існує, і шлях у `src` збігається з ним до букви (на хостингу регістр важливий).
3. Покажи результат: кількість карток до → після, скільки лишилось заглушок, розмір фото. Рахуй тільки справжні рядки карток, а не згадки в коментарях:
   ```bash
   grep -cE '^ *<button type="button" class="work" data-work' index.html   # усі картки
   grep -cE '^ *<button[^>]*class="work".*work__bg' index.html            # заглушки
   ```
4. Якщо працює `npm run serve` — запропонуй глянути `http://127.0.0.1:8000/#portfolio` і клікнути нову картку (має відкритись лайтбокс із фото й підписом «<опис> · 1 / N»).

## 5. Завершити

- Запропонуй коміт `Портфоліо: <опис>` — і **спитай перед комітом** (у коміт ідуть `index.html` і нове фото; `styles.css`/`script.js` не змінюються).
- Якщо сайт уже публікувався як artifact для Максима — запропонуй оновити його тим самим посиланням.
