# PRO CEILING — план практичного проєкту

## Мета
Це навчальний проєкт: після курсів Anthropic Academy (Claude 101, Cowork, Claude Code 101,
Agent Skills, Subagents, Claude Code in Action) відпрацювати **на практиці** все з курсів —
CLAUDE.md, skills, hooks, субагентів, MCP, плагіни — на справжньому сайті.

Сайт — лендинг фірми натяжних стель **PRO CEILING**.

**Як допомагати:** користувачка вчиться (18 років). Пояснювати українською, простими словами.
На кожному кроці казати, **що** робимо, **навіщо** і **з якого уроку курсу** це. Частину дій
давати робити їй самій (Shift+Tab, /init, /agents, /hooks), підказуючи.

## Кроки (кожен — тема з курсів)
1. **Git + перший коміт** «як є з дизайну». *(CC101 3.1, 3.3)*
2. **Plan mode** (Shift+Tab): план перетворення v3 у звичайний HTML + CSS без `support.js`; виконати. *(CC101 2.2, 3.1; In Action 1.1)*
3. **/init → CLAUDE.md** проєкту (бренд, кольори, правила, «заглушки не вигадувати»); особистий `~/.claude/CLAUDE.md`. *(CC101 4.1; In Action 2.1)*
4. **Skill «add-portfolio-item»** — додати роботу в портфоліо за шаблоном. *(Agent Skills 1–3)*
5. **Verification skill** — перевірка сайту: валідний HTML, посилання, картинки, телефони. *(In Action 2.2)*
6. **Hook PostToolUse** — після кожного редагування перевірка, exit 2 при помилці. *(CC101 4.5; In Action 2.4)*
7. **Hook PreToolUse** — захист контактів/телефонів від випадкових змін. *(In Action 2.4)*
8. **Субагент-рецензент** (лише читання, формат звіту + Obstacles): тексти, SEO, мобільний вигляд. *(Subagents 1–4)*
9. **Claude in Chrome (MCP)** — відкрити сайт і перевірити вигляд у браузері. *(CC101 4.4)*
10. **Запакувати** skills/hooks/агента в **плагін**. *(In Action 4.2)*

Далі (за бажанням): реальні фото, форма заявки (Telegram-бот), публікація на хостинг.
